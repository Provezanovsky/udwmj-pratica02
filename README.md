# UDWMJ - Prática 02

Atividade da disciplina de Desenvolvimento Web (UDWMJ), com exercícios introdutórios de HTML, CSS e JavaScript.

## Arquivos

- `pratica02exercicio01.html` - JavaScript com `alert()` no `body`.
- `pratica02exercicio02.html` - JavaScript com `alert()` no `head`.
- `pratica02exercicio03.html` + `pratica02e03.js` - JavaScript em arquivo externo.
- `pratica02exercicio04.html` + `style.css` + `script.js` - solicita o nome com `prompt()` e exibe uma saudação formatada por CSS externo.

## Como executar

Abra cada arquivo `.html` diretamente em um navegador.
